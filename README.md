# ⏳ 倒计时网页

一个简洁好用的网页倒计时工具，打开浏览器就能用。

## ✨ 功能

- **5分钟倒计时** — 适合番茄钟、做题计时、会议控时等场景
- **可视化进度环** — SVG 圆形进度条，剩余时间一目了然
- **颜色预警** — 剩余 60 秒变橙色，剩余 30 秒变红色并闪烁
- **三个按钮** — 开始、暂停、重置，操作简单直观

## 🚀 使用方法

1. 下载 `countdown.html` 文件
2. 双击用浏览器打开
3. 点击 **开始** 即可倒计时

> 不需要安装任何软件，有浏览器就能用！
